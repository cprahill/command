## What you get
**30 distinct concepts** (not 30 variants of the soap bar).

Combine lanes (2 only, as asked):
1. **Bar Stamp** — COMBINE-soap refined
2. **Peel Blob** — COMBINE-monogram refined

Neon is one lane: **Neon Vinyl**.

Everything else is a different idea: liquid &, die-cut S, condensed stack, factory stamp, twin S, kraft band, bubble S, gold seal, split type, script shop, burst badge, Venn, drop ticket, slap-on-soap, peel ampersand, soap-as-ampersand wordmark, box logo, fat ss, split vinyl/soap S, stencil, ribbon swirl, mirror SS, app icon, peel-bar wordmark, rubber stamp, enamel pin, holo foil.

## How to pick
Yes / Later / No on each card. Picks save on the device. Export JSON if you want a Drop copy.
